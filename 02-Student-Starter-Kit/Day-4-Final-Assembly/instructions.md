# Day 4: Final Assembly and Presentations

## What's in this folder
Nothing new to build - today is about combining, testing, and
presenting what the whole class built together.

## Steps


1. **Copy in the finished feature files.** Into your html base copy's
   `features/` folder, copy each group's finished file over the
   matching stub:
   - `streaks.js`
   - `milestones.js`
   - `shifts-calculator.js`
   - `spending-log.js`
   - `image-theme.js`


2. **Test it as a class.** Open the combined `index.html` together.
   Add a goal, log progress, try every feature. If something
   doesn't work, that group can debug their file live.

3. **Presentations.** Each pair presents their feature:
   - What does it do?
   - Show it working in the combined app.
   - Explain one piece of code from your file that you understand
     well - even a single line is great.

## What everyone should walk away with
- A saved copy of the fully combined app (this is theirs to keep
  and keep using)
- An understanding of at least one full feature, start to finish
- Practice explaining code out loud, which is a real skill on its
  own
