# CAG - Secure the Bag - Workshop

A 4-day workshop where girls (ages 12-18) build a savings goal
tracker app, learning HTML, CSS, and JavaScript along the way.

## Folder guide

### 01-Complete-App
The finished, fully working app in one place (`index.html`,
`style.css`, `script.js`). Use this to demo the end goal on Day 1,
or as a reference if you need to double check what something
should look like.

### 02-Student-Starter-Kit
What you hand out to the girls, one subfolder per day:
- **Day-1-Structure-and-Style** - HTML is done, CSS has TODO
  sections to fill in together, JS is empty
- **Day-2-Core-Logic** - HTML/CSS from Day 1, JS has TODO sections
  for the core add-goal and log-progress logic
- **Day-3-Feature-Files** - a working core app plus 5 empty
  feature files (`streaks.js`, `milestones.js`,
  `shifts-calculator.js`, `spending-log.js`, `image-theme.js`),
  one per pair, each with step-by-step TODOs
- **Day-4-Final-Assembly** - instructions only, for combining
  everyone's finished feature files and presenting

Each day's folder is the STARTING point for that morning. Hand out
the next day's folder once a day wraps.

### 03-Instructor-Code-Along
My answer keys, matching the same day structure, so I always
have a working reference while live-coding with the class:
- **Day-1** - fully styled app, no JS yet
- **Day-2** - fully styled app with the core logic completed
- **Day-3** - fully working core plus all 5 features completed
- **Day-4** - the final combined app (same as 01-Complete-App)

### 04-Slide-Decks (still working on them)
A short slideshow for each day (10-15 minutes of teaching content),
covering just the concepts that day's lesson needs, with quick
quizzes to check understanding before hands-on time starts:
- **Day-1-Structure-and-Style.pptx** - what HTML and CSS are
- **Day-2-Core-Logic.pptx** - what JavaScript is, variables, functions
- **Day-3-Feature-Files.pptx** - how the feature files talk to core.js
- **Day-4-Final-Assembly.pptx** - combining everything and presenting

## How the groups work
Students use vscode + Copilot. 
On Day 3, each pair is assigned one feature file and works independently -
since every feature lives in its own file, there's nothing to
merge and no risk of two people editing the same lines.
